# Simple Skyblock player tracker
Tracks activity of a skyblock player on a **Discord bot** using **hypixel API**

## Requires:
(put the tokens and pi in a .env file)
- Hypixel api [here](https://developer.hypixel.net/)
- Discord Bot token [here](https://discord.com/developers/home)
### Packges required:
- python-dotenv
- discord.py
- requests

After making everything you can go to a discord channel and type /track and it should show a option like this
